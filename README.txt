BOJO 46 TIO CUCHO — prototipo inicial

Incluye una interfaz web adaptable, asientos locales, apodo visible y una mano de cartas de demostración.

IMPORTANTE:
- No es todavía un juego multijugador en tiempo real.
- No hay autenticación real, servidor compartido, audio, pagos ni notificaciones automáticas.
- No usar para apuestas reales.
- Para una mesa real, hace falta añadir backend seguro, reglas completas, sincronización y pruebas.

Publicación gratuita de la interfaz estática:
1. Crear un repositorio nuevo en GitHub.
2. Subir index.html.
3. En Settings > Pages, activar publicación desde la rama principal y carpeta raíz.
4. Esperar a que GitHub Pages confirme la URL.
Esto publica solo el prototipo estático; no crea las funciones de servidor.
